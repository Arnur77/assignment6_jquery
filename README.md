# Assignment #6 — jQuery

A simple student project demonstrating jQuery selectors, effects, DOM manipulation and animations.

## Features

- Task 0: jQuery CDN setup and document ready message.
- Task 1: ID, class and tag selectors; `.text()`, `.html()` and `.css()`.
- Tasks 2–4: `.hide()`, `.show()`, `.toggle()`, fade methods and slide methods.
- Tasks 5–7: `.append()`, `.prepend()`, `.remove()`, `.attr()`, `.val()` and `.text()`.
- Tasks 8–10: basic, sequential and combined `.animate()` examples.
- Task 11: interactive image gallery mini project.

## How to run

1. Download or clone this repository.
2. Open `index.html` in a browser.
3. Use the navigation bar to open each assignment part.
4. Internet connection is needed to load jQuery and the example images from their CDNs.

## Technologies

- HTML5
- CSS3
- JavaScript
- jQuery 3.7.1
